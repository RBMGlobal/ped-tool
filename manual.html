PED Field Manual

PED is a single HTML file — and an Android app built from that same file — for working up an operational picture on a map and handing it to ATAK as a data package. Plot and edit in bulk here, where it is quick, then export once. Everything runs on the device you open it on.

—Quick start: a package into ATAK in five minutes

Sections 1–9 below follow the panels down the sidebar, in order. If you only ever do one thing with this tool, it is the sequence here.

  1. 1

    Open it

    Double-click PED_tool.html (any browser) or open the PED app. If you were working on something last time, a bar offers to Restore it — take it, or Start blank.

  2. 2

    Name a layer

    In Layers — key & filter, click the name Layer 1 and type what these points are — "Blocking positions", "Reported incidents". Set its Default icon so everything you add gets the right TAK symbol without touching each point.

  3. 3

    Get the locations in

    Three ways, all in Plot points: type a coordinate and press Add point; press Pick on map and click; or paste the messages you were sent into Bulk paste and press Scan for coordinates. Files — a WhatsApp export, CSV, KML, GPX, Word, PowerPoint — just get dropped onto the map. See section 5.

  4. 4

    Check each point

    Click a marker. Set its affiliation (hostile / friendly / …), its type, its Layer, and anything worth saying in Notes — notes become the marker's remarks in ATAK. Attach a photo if you have one.

  5. 5

    Export and import

    Export TAK — everything (one package) gives you a single .zip. In ATAK: Import Manager → Local SD and pick it (or drop the zip into atak/tools/datapackage first). In the Android app the export opens the share sheet — choose ATAK and it goes straight in.

Before you rely on it

On a new TAK build, export one point, one route and one area first and check they land the way you expect. Shape and icon handling varies a little between ATAK versions.

01Project — save & restore

Save (.json) writes everything — points, routes, areas, imagery overlays, attachments, custom icons, your planning speed — into one file. That file is the backup and the way you hand work to someone else. Load / import… opens it again, and is also the button for importing any other format.

Autosave is a safety net, not a backup

The tool saves to the browser's own storage as you work and offers it back next time you open the file. That storage belongs to that browser on that device — it does not travel with the HTML file, it is lost if the browser data is cleared, and very large attachments or imagery can exceed what it will hold. Save a .json at the end of anything you care about.

Why the same project file matters

Every item exports with an identifier built from the project it belongs to. Re-export from the same project and ATAK updates the markers you already sent. Start a fresh project and export the same points, and ATAK treats them as new ones — you get duplicates. So: one project file per operation, kept and reloaded.

Google hyb

This uses the unofficial tile endpoint that community ATAK map sources use — not the paid Google Maps API. It can stop working without notice and its use sits in a grey area of Google's terms. Treat switching it on as a team decision, not a default.

Imagery capture date

On Satellite and Sat hybrid, a small chip in the corner of the map shows when the imagery under the centre of your view was taken, and updates as you move. For a specific spot, press Imagery capture date and click it — you get the date, the resolution and the source. This needs internet, and only Esri publishes it; Google and Mapbox don't.

Terrain

Hillshade relief lays shaded relief over whichever basemap you are on, which makes valleys, wadis and drainage lines read at a glance. Elevation profile then takes two clicks and draws a cross-section between them with the drop, the relief and the steepest slope; each route card has a Profile button that does the same for the whole route.

Resolution

The elevation model is roughly 30 m. It resolves valleys and large wadis honestly. It will not show a narrow erosion gulley that could still stop a vehicle — ground-truth those.

Zoom to everything frames all your plotted work. Show data table swaps the map for a table of every point — the fastest way to check a batch you have just imported. Press it again for the map.

03Layers

Layers are yours to define — they are how you group the picture and how you export it in pieces. Click a layer's name to rename it. The tick box hides and shows it on the map. The count on the right is how many points it holds. ✕ deletes the layer and its points (Ctrl+Z brings them back). + Add layer makes another.

Default icon

Each layer has a Default icon — an affiliation, or a specific type such as Infantry or a coloured spot dot. Every point in the layer that you have not overridden individually follows it, so changing one dropdown re-symbolises the whole layer. Points you have set by hand keep what you gave them, and the tool tells you how many it left alone.

Moving points between layers

  • One point: open its popup and change the Layer dropdown. Pick ➕ New layer… to create one on the spot.
  • Several: select them, then use Move selected to layer… in Select & bulk edit — which also offers a new layer.
  • On import: anything you drop that contains points asks where to put them first. See section 5.

04Plotting points

In the Plot points box, choose the coordinate format (Decimal °, D° M′ S″ or MGRS), the layer, the affiliation and the type, then type the coordinate and press Add point. Or press Pick on map and click the position — Esc stops picking.

The marker popup

Click any marker. From top to bottom you get:

  • Its current type and layer, the coordinate in decimal, DMS and MGRS, and the exact CoT type it will export as.
  • Affiliation — seven buttons, click to change.
  • Type / role — unit types, sites, waypoint, or a coloured spot dot.
  • Layer — move it, including to a new layer.
  • Notes — free text; becomes the marker's remarks in ATAK.
  • Attachments — photos or files, which travel inside the data package and open from the marker in ATAK. Large images are downscaled automatically so packages stay transferable.
  • Move (drag) to reposition it, Delete to remove it, and the tick box to include it in a selected-points export.

Team iconset (ATAK)

If your ATAK devices already carry a custom iconset, copy an icon's path out of ATAK's Iconset Manager — it looks like 34ae1613-…/Ops/vcp.png — and add it under Team iconset (ATAK) with a name and a stand-in colour. It then appears in every type dropdown. Points using it export with that iconsetpath, so they render as your own symbol on the device; on this map they show as a coloured pin. Custom icons are saved with the project.

05Bringing coordinates in

Anything can be dropped straight onto the map, or opened with Load / import…. Anything containing points asks which layer first — an existing one, or a new layer named after the file. Where a file also holds routes or areas, you can skip its points and still take the rest.

Drop thisAnd you get
.zipA WhatsApp chat export — see below. Any other zip is unpacked and its KML / CSV / GPX / GeoJSON imported
.csvPoints. Needs lat+lon columns or an mgrs column, with headers in row 1
.kml / .kmzPlacemark points, LineStrings as routes, Polygons as areas — geometry kept exactly

CSV columns

Beyond position, the importer recognises name, id, layer, affiliation, role, notes and color (and common synonyms — callsign, group, remarks, lng, y/x). A layer column wins per row and creates layers as needed, so a spreadsheet can arrive pre-sorted.

Bulk paste — the everyday route

Paste anything into Bulk paste — WhatsApp messages, a sitrep, text out of Word or an email — and press Scan for coordinates. Every coordinate found comes back as a tick-list: names already filled in from the surrounding words, anything within ~15 m of an existing point flagged dup?. Untick the false hits, fix the names, choose the layer, and Add ticked points.

Format readExample
Decimal9.0765, 7.3986
LabelledLat: 12.47464200, Long: 7.65343700
DMS9°04′33.6″N 7°23′52.8″E
MGRS32PLU 47680 65126
Shared pinmaps.google.com/?q=11.7642,7.5531

A number needs at least two decimal places to count, which is what stops dates, version numbers and phone numbers being read as positions. Where one message carries several locations, each one is named from the words next to it rather than from the whole sentence, so a report that runs "… X located around Dutsinma Road on Lat/Long …, and Y located around Kofar Fada Kuki on Lat/Long …" gives you two properly distinct points.

WhatsApp chat exports

In WhatsApp, open the chat → Export chat → With media if you want the photos. Drop the .zip straight onto the map. Out of it you get:

  • Shared pins as well as typed coordinates.
  • A name for each point, taken from the message beside the pin — or the sender and time if there is nothing to go on.
  • Notes carrying the sender and timestamp, the phone number quoted with that location, and the original message text — all of which end up in the ATAK remarks.
  • Photos sent with a pin, attached to that point and travelling inside the data package.

Short links carry nothing

A pin shared as a maps.app.goo.gl link contains no coordinates at all — not in the export, not anywhere offline. The scan counts them and tells you how many it found so nothing goes unnoticed; open those links in a browser and paste the full URL from the address bar. Photos sent normally have their location data stripped by WhatsApp, so a photo without a pin beside it gives no position either.

06Routes

Paste a Google Maps directions link — a full .../maps/dir/… URL that contains coordinates — name it, and press Add route. Stops are read in order and each leg is snapped along roads at full resolution, around 5 m fidelity. Set Planning speed and every route card shows distance and an ETA.

Each route card carries Edit stops (drag the stops, the route re-snaps), Reverse, Profile for a terrain cross-section of the whole route, and its own TAK export.

Road choice, not road accuracy

Snapping follows OpenStreetMap routing. The line sits on the road accurately, but at some junctions OSM will choose a different road than Google would. Eyeball the route before anyone drives it. For Google's exact line, build the route in Google My Maps, export it to KML/KMZ, and drop that on the map — imported geometry is kept untouched, and the route list labels it as imported.

A shared maps.app.goo.gl short link carries no coordinates; the tool opens it for you so you can copy the full URL out of the address bar.

07Threat areas

Draw area — click each corner, then double-click or press Enter to close it. Draw circle — click the centre, then click the edge to set the radius. Esc cancels either.

Each shape can be renamed, recoloured and given notes, and exports as a TAK drawing — polygons as u-d-f, circles as u-d-c-c with a true radius, so they arrive as editable shapes rather than pictures.

08Imagery overlays

Add imagery (GeoTIFF / image)… — or drop the file on the map. A georeferenced .tif places itself. A plain PNG or JPG (a screenshot, an air photo, a scanned annex) is placed with three corner handles you drag until it sits right.

Each overlay gets its own transparency slider and saves with the project. Export TAK package — all imagery sends them to ATAK as KMZ ground overlays (GRGs), and they are included when you export everything in one package.

Package size

Imagery is by far the biggest thing you can put in a package. Large overlays make files that are slow to move onto a device and can push the browser autosave past its limit — the .json save always keeps them.

09Select & bulk edit

This is what makes the tool worth using over editing in ATAK. Select points by:

  • the tick box in a marker's popup,
  • Box select — drag a rectangle, or just Shift+drag on the map,
  • Select points in view — everything currently on screen.

Then, on the whole selection at once:

  • change the icon — any affiliation, type or spot-dot colour,
  • Move selected to layer…, existing or new,
  • Delete selected points, undone with Ctrl+Z,
  • export just the selection as a package, KML or CSV.

Getting a package into ATAK

  • Android app: the export opens the share sheet — choose ATAK.
  • ATAK, file already on the device: Import Manager → Local SD → pick the .zip.
  • ATAK, moving it across: copy the zip into atak/tools/datapackage, then Import Manager.
  • WinTAK: File → Import.

What arrives

Points come in as markers of the right affiliation and type, carrying your notes as remarks, your attachments as files that open from the marker, and — for spot dots and team icons — the right colour and iconset path. Routes arrive as TAK routes with their full geometry, areas as editable shapes. Everything is marked to persist rather than expire.

Re-exporting

Export the same project twice and ATAK updates the items rather than duplicating them — which is why the project .json is worth keeping. Change something here, export again, and the picture on the device corrects itself.

11The web link & the Android app

Opening it from a web link

The tool can also be published to a web address, so nobody has to be sent a file — open the link and it is there, always the current version. On a phone or tablet, open it once and use Add to Home Screen (Chrome: menu → Add to Home screen; Safari: the share button). From then on it launches like an app and keeps working with no signal: the tool, your saved work and every function are held on the device.

Offline means the tool, not the map

Basemap tiles come from the provider each time, so out of signal you get a blank map background with all your points, routes and areas on it — exactly how the local HTML file behaves today. Imagery you need in the field should be brought in as a GeoTIFF overlay, which is stored with the project.

From a browser, exports download to the device's Downloads folder — open ATAK's Import Manager → Local SD and pick the file from there.

The Android app

The app is the same tool wrapped for Android, so anything in this manual applies to both. The one difference is exports: instead of downloading, they open the system share sheet, so you can hand a package to ATAK on the same device without touching a cable.

  • Installing: copy PED_v1.7_debug.apk to the device, open it from the Files app, allow installing unknown apps when asked.
  • Updating: install the new APK over the old one. Your autosaved work survives.
  • Permissions: internet only, for basemap tiles and road snapping. It is fully usable offline.
  • Requirements: Android 7 or later.

Before switching build machines

Updates only install over the top while every APK is signed with the same key. An APK built somewhere else has to be uninstalled first, which wipes the autosave. Save your project to .json before any update you are unsure about.

12What leaves the device

Nothing you plot is ever uploaded. There is no account, no server, no sync. Points, routes, areas, notes and photos exist only in the file you are working in and the packages you export. What does go out is limited to the following, and each stops the moment you work offline or leave that feature alone.

FeatureTalks toSends
Basemap tilesWhichever provider you pickedThe map area you are looking at
Snap to roadsrouter.project-osrm.orgThe stops of that route
Imagery capture dateEsri metadata serviceThe point or view you asked about
Hillshade reliefEsri tilesThe map area you are looking at
Elevation profileopentopodata.orgThe sampled coordinates of the line
Open in Google MapsGoogle MapsThat one coordinate, when you click the link

A Mapbox token you type is kept in that browser only and never written into a project file, so a .json you send to a colleague carries no credentials. Work with an offline basemap and snapping unticked and the tool makes no network requests at all.

CThings that catch people out

  • Short links are empty. maps.app.goo.gl pins carry no coordinates. Open them and copy the full URL.
  • Autosave is not a backup. It lives in one browser on one device. Save the .json.
  • Start from the same project file each time, or re-exports arrive in ATAK as duplicates instead of updates.
  • Snapped routes follow OSM's road choice, which is occasionally not Google's. Look at the line before it is driven.
  • 30 m elevation misses narrow gulleys. It is honest about valleys, not about erosion channels.
  • WhatsApp strips photo location data. A photo alone is not a position.
  • Imagery dates only exist on the Esri basemaps. Google and Mapbox don't publish theirs.
  • Big imagery makes big packages — check the file size before trying to move one onto a device in the field.
  • Spot-check a new TAK build with one point, one route and one area before pushing to the team.
